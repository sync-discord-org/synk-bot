# synk-bot

A bot for Discord using JS.

## Installation

1. Install Node.js (20+)
2. Run `npm init -y`
3. Run `npm install discord.js dotenv`
4. Create a `.env` file in the root folder
5. Add your bot token to the `.env` file: `DISCORD_TOKEN=`
6. Run `node index.js`

## Commands

- `/set-ticket-chat` - Set the ticket chat channel
- `/create-ticket-role` - Create a ticket role
- `/add-ticket-admin` - Add a user as a ticket admin
